# forum-sportif
Forum Sportif est une plateforme communautaire permettant aux passionnés de sport de trouver des lieux de pratique dans leur zone de localisation et d’échanger avec d’autres utilisateurs sur différents sujets sportifs.

Le projet combine forum, géolocalisation, recherche de lieux sportifs et interactions communautaires. Les utilisateurs peuvent découvrir des terrains, gymnases, clubs, parcs, pistes ou espaces sportifs selon leur position et le sport recherché.

La plateforme vise à faciliter l’accès au sport, créer des liens entre pratiquants et centraliser les informations utiles sur les lieux de pratique.

Fonctionnalités principales :

* Forum de discussion sportif
* Recherche de lieux par sport
* Géolocalisation
* Carte interactive
* Publications et commentaires
* Profils utilisateurs
* Catégories sportives
* Avis sur les lieux
* Signalement de lieux
* Communauté locale
